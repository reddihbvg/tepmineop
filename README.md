# tepmineop Texture Pack

Официальный текстур-пак для **Minecraft Bedrock Edition (версии 1.21.131+)** от компании **Tepmine**. Данный пак полностью преобразует графику и звуковое сопровождение игры, делая геймплей более динамичным и стильным.

---

## 🌟 Главные преимущества и фишки

* **Маленькие предметы:** Мечи и другие инструменты уменьшены в размере, что значительно увеличивает обзор и делает пак идеальным для PvP и обычного выживания.
* **Прикольные звуки:** Полностью переработанные аудиоэффекты для блоков, окружения и боевых действий.
* **Музыка в меню:** Кастомное музыкальное сопровождение при запуске игры.
* **Красивые кнопки:** Полностью измененный, чистый и стильный дизайн интерфейса с прозрачными элементами UI.
* **Крутая анимация разрушения:** Обновленная визуализация трещин при ломании блоков.

---

## 🛠️ Переменные версии (Denyok Config)
> Настройка статуса сборки для разработчиков:
* `denyok = 0` — **Публичная версия** (доступна для всех)
* `denyok = 1` — **Тестовая версия** (отображается предупреждение)
* `denyok = 2` — **Проверка стабильности**

## 📥 Скачать бесплатно

Вы можете установить текстур-пак в один клик с помощью официальных файлов импорта:

* **[Скачать .mcpack](https://github.com)** (Рекомендуется для автоматической установки)
* **[Скачать .mcaddon](https://github.com)** (Если текстур-пак идет в комплекте с модификацией)

### Инструкция по установке:
1. Скачайте файл `.mcpack` на свое устройство.
2. Запустите скачанный файл (на смартфоне просто нажмите на него и выберите «Открыть через Minecraft»).
3. Игра автоматически импортирует пак. Перейдите в *Настройки* -> *Глобальные ресурсы* и активируйте **tepmineop**.
